## 二、打分公式落地

```js
// lib/score.js —— 每个负向标签独立计分，不去重、不合并
export function avoidFactor(cue, candidate) {
  const avoid = Array.isArray(cue?.avoidTargets) ? cue.avoidTargets : []
  const probs = probabilities(candidate?.analysis)
  if (avoid.length === 0 || !probs) return { factor: 1, parts: [] }
  let pressure = 0
  const parts = []
  for (const item of avoid) {
    const weight = Number(item?.weight)
    if (!Number.isFinite(weight) || weight <= 0) continue
    const raw = Number(probs[item.tag])
    const p = Number.isFinite(raw) ? Math.max(0, Math.min(1, raw)) : 0
    pressure += weight * p
    parts.push({ tag: item.tag, weight, p, impact: Number((AVOID_K * weight * p).toFixed(4)) })
  }
  const factor = Math.max(1 - AVOID_K, 1 - AVOID_K * pressure)   // 封顶：最低 0.4
  return { factor: Number(factor.toFixed(4)), parts }
}

export function scoreCandidate(cue, candidate) {
  const result = scoreTarget(cue?.target, candidate?.analysis)  // base = Σw⁺·p / Σw⁺（原有口径）
  const avoid = avoidFactor(cue, candidate)
  const score = Math.max(0, Number((result.score * avoid.factor).toFixed(3)))
  return { score, coverage: result.coverage, parts: result.parts, avoid }
}
```

权重归一化（`normalizeAvoidTargets`）：3 个 → 各 1/3（舍入余量补第一个 → 0.34/0.33/0.33）；5 个 → 各 0.2。

## 五、偏离文档的地方（4 处，均有理由）

1. **同一 tag 写两遍会被合并**。文档说「不去重、不合并」——我理解针对的是**相关但不同**的标签（happy 与 upbeat 各自独立计分，已按此实现）；完全相同的 tag 把同一个概率乘两遍没有意义，所以合并。要严格到「同 tag 也各算一次」，改一行即可。
2. **`avoidKeywords` 保留**（人声 → 标题里的 vocal/feat 扣分）。它在**检索阶段**给候选池打整数分，和 0–1 的最终分不是同一套；文档说的「不要并存两套扣分逻辑」我按「不要两个标签惩罚」理解。若要严格只有一套，砍掉它，「忌人声」就只剩「无法验证」chip。
3. **「本段最多压」恒为 60%**。文档例子是「34%」，但 k=0.6 + 权重归一化到 1 时上限必然是 60%；34% 只在权重不归一化时才可能出现，与第 2 节公式矛盾。我按公式实现；若想显示动态值（如「当前候选平均被压 22%」），可以改。
4. **显式空数组 = 用户清空**。否则在工作台删光忌项后，下次读表又会从 `avoids`（比如「欢快」）自动补回，删不干净。旧表（没有该字段）仍从 `avoids` 推导。
